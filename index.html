An end-to-end, self-evolving system where AI agents autonomously optimize every layer of the inference stack, from GPU kernels to serving infrastructure and more, built by the whole community.

Iteration 1

Throughput doubled. Quality preserved.

We gave Claude a single task: make this inference engine faster. Over 10 sequential sessions with no human intervention, it evolved mini-sglang from 512 to 1,016 tok/s (+98%) on Qwen3-0.6B / RTX PRO 6000 Blackwell — writing 3,700 lines of Triton and CUDA, fusing kernels, introducing INT8/INT4 quantization, and redesigning the attention mechanism. After fixing all implementation bugs, the evolved engine matches vanilla within noise on IFEval, GSM8K, and MMLU Pro.

Decode throughput (tok/s) measured after each trial on Qwen3-0.6B / RTX PRO 6000 Blackwell.

View the evolved code on the trial-10 branch of our mini-sglang fork.

The Scaffold

Three components. That's it.

Fresh sessions, a single scalar signal (tok/s), and a shared learning.md file. No multi-agent framework, no orchestrator, no learned reward model. The agent reads its own prior notes, profiles the system, decides what to try, and writes back what it learned.

Trials 1–3

Kernel Fusion +32%

Fused RMSNorm+GEMV, QKNorm+RoPE+KV, and split-K attention to cut kernel launch overhead.

Trials 4–6

Quantization +27%

INT8 weight quantization halved weight traffic from 983 MB to ~490 MB per step.

Trials 7–10

System-Level +18%

Multi-step CUDA graphs, in-graph argmax, and metadata pre-allocation.

Kernel Analysis

Opening the hood on 3,700 lines of agent-written GPU code

We audited every kernel the agent produced. The result: 8 genuinely impressive optimizations, 5 bugs (3 silent correctness issues, 2 race conditions), and ~1,200 lines of dead code. The agent discovered non-obvious trade-offs — like computing RMSNorm 2,048× redundantly being faster than computing it once and synchronizing.

Join Us

This is an open, community-driven project. We're just getting started.

Iteration 1 proved the concept: AI agents can write real, production-quality inference systems and double throughput with zero human guidance. But a single model on a single GPU is just the beginning. We want to evolve serving systems end-to-end including but not limited to scheduling, batching, memory, cache, multi-GPU, new architectures, etc. and we want to do it together.

Whether you're a kernel engineer, an ML researcher, an infrastructure builder, or just someone who thinks this is interesting, come build with us!
